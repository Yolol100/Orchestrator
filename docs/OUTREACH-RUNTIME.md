# Leads research runtime boundary

- Processcontroller: `webactueel-workflow`.
- Specialist: `leads`.
- Leadscanner runtime: `Yolol100/Leadscanner` for company discovery, evidence validation, privacy-safe private register updates and read-only historical suppression.
- No mailbox bridge, message drafts, delivery, IMAP, SMTP, campaign execution or automated follow-ups.
- Historical suppression, bounced addresses, opt-outs and existing records remain protected and must never be reset.

Orchestrator transports only approved research operations. The full previous implementation is retained on branch `archive/pre-myhost-mail-cleanup-2026-11-10`.
